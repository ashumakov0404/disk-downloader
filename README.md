# Disk Downloader

Disk Downloader скачивает файлы с Яндекс Диска и Google Диска на Windows. Можно забрать целую папку, поставить несколько папок в очередь или выбрать отдельные файлы и хранить их на компьютере.

[Скачать установщик для Windows x64](https://github.com/ashumakov0404-spec/cloud-drive-downloader-downloads/releases/latest/download/DiskDownloader-Setup.exe) · [Выпуски и ZIP](https://github.com/ashumakov0404-spec/cloud-drive-downloader-downloads/releases/latest)

## Как начать

1. Скачайте и запустите `DiskDownloader-Setup.exe`. Установщик версии 2.2.32 без цифровой подписи, поэтому Windows SmartScreen может показать предупреждение.
2. **Публичные ссылки Яндекса.** Вставьте ссылки «Поделиться» по одной на строку, выберите папку на компьютере и нажмите «Скачать / продолжить». Для этих ссылок вход в аккаунт не нужен.
3. **Свой Яндекс Диск.** Откройте «Доступ к своему Диску», введите логин и пароль приложения для WebDAV. Укажите путь к нужной папке или `/` для всего Диска.
4. **Google Диск.** В настройках откройте «Профили и автосинхронизация» и добавьте профиль Google. Для первого входа нужен [OAuth-клиент типа Desktop app](https://developers.google.com/identity/protocols/oauth2/native-app#creatingcred) с включённым Google Drive API. После входа выберите облачную и локальную папки.

## Загрузки и облачные папки

- При обычной загрузке сохраняется структура папок. При желании можно сложить файлы в одну папку или проверить уже скачанные копии перед началом.
- Очередь сохраняется после закрытия приложения и перезапуска Windows. После завершения загрузки кнопка «Повторить только ошибки» запускает повтор для оставшихся файлов.
- У каждого профиля своя локальная папка и свой переключатель автосинхронизации. Для автоматического поиска новых файлов Яндекса понадобится OAuth-токен с доступом на чтение Диска.
- В «Облачных файлах» можно искать по имени и пути, скачивать отдельные файлы и включать автосинхронизацию для выбранных папок. Чтобы видеть облачные файлы в Проводнике, подключите профиль к пустой папке на локальном диске NTFS. Содержимое скачивается при открытии или закреплении файла.

Синхронизация идёт из облака на компьютер. Локальные изменения не отправляются обратно, а удаление файла в облаке не удаляет скачанную копию.
